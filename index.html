ABOUT THIS WORKSPACE

Transparent by design.

This lightweight edition is designed for quick, privacy-conscious intake and preliminary examination. It intentionally avoids claiming that a heuristic can prove steganography or anti-forensics.

01

Integrity first

Computes a SHA-256 digest in the browser. The digest identifies the exact bytes examined; it does not prove where a file came from.

02

File identification

Compares common file signatures with the file extension where possible. Signature mismatches are triage flags, not definitive evidence of tampering.

03

Metadata review

Reads basic image dimensions and selected JPEG/PNG metadata indicators. Browser parsing is limited and does not replace a forensic metadata suite.

04

Pixel screening

For supported images, checks simple least-significant-bit distribution indicators. Natural image content can trigger these heuristics; dedicated steganalysis requires validated models and datasets.
